# ADR-0023: Reviewed preproduction workplace spreadsheet import successor

**Scope:** This decision approves only the exact preproduction source-lock successor below under [ADR-0020](0020-review-exact-preproduction-schema-successors.md). The current canonical SQL, transition manifest, schema lock and its protected check remain unchanged by this approval-only commit. This is not authorization for deployment, operational restore, release, populated beta cutover, or billing activation.

## Product decision

A coach explicitly reviews the normalized source rows, owned active workplace(s), teacher-local day and timezone, relevant revisions, stable learner identities and effective enrollment before approving the batch. A row can use a single owned target, or an explicit distinct set of owned workplace IDs. A unique name can resolve a workplace; an ambiguous name is never guessed. Distinct selected owned learner IDs may share a name; repeated IDs, unresolved ambiguous identities and duplicate rows cannot be silently merged. Archived existing learners cannot receive current enrollment through this import; an explicitly reviewed new archived identity receives no current enrollment. The import neither grants contact authority nor changes payments, finance, credits or historical attendance.

Fresh writes require the exact reviewed envelope and explicit confirmation and recheck day, venue and identity state inside one transaction. A failed row or target rolls back the batch. Exact owner-scoped receipts can replay even after a workplace is retired; changed content under the same key fails. Old array payloads can only replay already-applied exact historical receipts, never create fresh writes. This is not a guarantee of tenant-wide name uniqueness.
