## Outside this implementation pass

- The coach UI design comparison and rollout are separate from functional source work.
- A real-client pass with an invited coach in ChatGPT and Claude and an assistive-technology pass are not replaced by scripted browser or delegated OAuth tests.
- The original clean beta release intentionally carried forward the one verified Auth identity, not old coaching records. If a later production transition handles populated data, require explicit scope, a verified independent off-host restore and preservation evidence for Auth, Storage, financial records and portal grants. The same decision is not required to keep developing on synthetic data.
- No current source change activates provider traffic, sends real correspondence, processes real payments, deploys the release or waives the operator's acceptance.
