## 2026-11-15 — checkout race and release verification lesson

The latest PR #81 commit `e6d2738` passed CI, security, Compose and backup/restore but its authenticated E2E had 259 passes, five intentional skips and one failure in `parity-configured-stripe.spec.ts`.
