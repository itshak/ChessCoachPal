# Historical privacy and redistribution triage — 2026-11-08

**Status: PARTIALLY TRIAGED; RELEASE BLOCKED.** ChessCoachPal is already a public GitHub repository. This is an evidence ledger, not an assertion that cached history or historic binary media has been purged. The release checklist and package version must remain unchanged.

## Evidence and scope

- Latest archived GitHub Actions audit: [main security run 42431856810](https://github.com/itshak/ChessCoachPal/actions/runs/42431856810). It listed 367 runs, successfully scanned 352 run-log archives, 122 artifact archives, 2,457 readable text entries, and 18 nested archives; it reported 0 high-confidence credential patterns, 151 heuristic alerts across 76 runs, 9 unavailable logs, and 83 oversized/unreadable entries.
- Latest accessible-ref source audit from the same run: 30 refs, 2,036 reachable objects, 889 text blobs and 0 high-confidence secret-pattern or suspicious-filename matches. This does not cover deleted/unreachable commits, external forks or cached source objects.
- The 151 alerts were 68 legacy-host flags, 68 nonfixture-email flags in CI logs, and 15 email-shaped flags in nested Playwright test artifacts. The scanner had an array-to-string de-duplication defect: 7 log runs repeated the same alert per rule. The corrected logic treats the original snapshot as historical evidence rather than claiming 151 independent exposures.

## Manual follow-up on the reported alert families

1. **15 artifact runs, downloaded and inspected:** All 15 flagged Playwright-result ZIPs were reviewed as nested archives, with 1,044 expanded entries (514 text entries, 514 classified image/video/binary entries, and 16 nested archive entries). The email-shaped text matches were 104 synthetic example.com occurrences and 409 Playwright screenshot-filename strings mistaken for email addresses (e.g. @ plus a trace image filename ending in .jpeg). No additional nonfixture email domain was seen in those readable texts. Binary screenshot/video frames have **not** been exhaustively inspected for non-text PII; do not represent them as cleared.
2. **61 CI Docker-log runs, individually inspected:** All 61 unique Actions runs that produced log candidates had retrievable Docker job logs. The email domains in those Docker logs were github.com and outlook.com; observed occurrences came from GitHub/Docker build provenance and commit author/committer metadata, not identified ChessCoachPal student records. The synthetic Supabase build argument used example.supabase.co. The remaining vercel.app host was **not** a fixture: it was the repository's previous, unrelated bridge URL included in GitHub's own repository metadata under homepage. Do not reproduce the legacy host string in public reports.
3. **Verified current metadata exposure:** GitHub's public [repository metadata](https://api.github.com/repos/itshak/ChessCoachPal) still advertised this legacy Homepage URL on 2026-11-08. Removing source references alone cannot correct repository metadata or past Actions logs. This is a confirmed privacy-cleanup action, although the URL itself is not an authentication credential. It can reveal an association with the prior project.

Record whether they are accepted as a documented residual risk or obtain additional GitHub-side deletion/retention/support evidence.

If a live secret is later found in any old/publicly reachable material, revoke/rotate it in the issuing provider immediately and investigate the time window; deleting the file does not revoke a secret.
