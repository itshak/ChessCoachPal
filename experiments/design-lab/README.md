# Isolated component comparison

This static Vite laboratory is independent of Next.js production routing, auth, secrets and database. It imports the same deterministic palette/student/session fixtures as the initial Next preview. It is not the chosen production framework. Run `npm install && npm run dev` here; `npm run build` makes a static preview. First CI run resolves the transitive lockfile and retains it as an artifact; commit the reviewed lock before treating results as reproducible. No external runtime calls or real data. The separate package is a temporary comparison boundary, not a new production dependency.

All candidates are pinned evaluation versions, not claims of latest: Base UI 1.9.0 (MIT; https://base-ui.com/react/overview/releases/v1-9-0), React Aria Components 1.21.1 (Apache-2.0; https://www.npmjs.com/package/react-aria-components), Ariakit 0.4.37 (MIT; https://ariakit.com/components). All advertise React 19 support; actual install/build and keyboard tests are the evidence. Base UI supports composable unstyled primitives; React Aria includes internationalized higher-level controls; Ariakit offers flexible stores and primitives. Compare actual interaction correctness and candidate chunk sizes, not package popularity.

The three adapters share roster, workplace menu, keyboard command dialog, lesson close and local receipt logic. Ariakit's objective currently uses Role.input with shared validation; complete a form-specific implementation before claiming full foundation acceptance. Copy and theme states remain provisional. The Next.js integration, logo variants, contrast of component states, screenshot matrix, accessibility audit and design approval remain open. CI artifacts are synthetic only.
