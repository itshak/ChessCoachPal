## Handoff

The canonical [schema](../../../specs/final-saas-schema/spec.md), [entitlement](../../../specs/freemium-entitlements/spec.md), and [professional persistence](../../../specs/recurrence-and-report-publication/spec.md) specs now own these requirements. The [remaining changes](../../README.md) implement feature behavior without planned DDL, starting with Workplace Context. Generated report sharing, recurring-edit UI and new provider adapters/rights, billing/checkout and app-level metering, real-client approval, and release remain separate. Any unforeseen schema requirement needs ADR-0019 review, not an edit to a frozen input.

Production cutover, target-specific identity/payer/portal mapping, encrypted off-host backup and independent restoration of private data, and external provider or payment activation require separate approval and evidence under ADR-0017/0019. Neither the proposed nor current source work accessed or changed that target.
