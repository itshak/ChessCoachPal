# Proposed task-oriented shared contract

Not an advertised tool registry or code. Names below are proposed additions to existing /mcp; verify collisions and exact existing OAuth scope names on implementation. All use strict root objects, unknown keys rejected, no teacherId, no generic execute/SQL. Web routes under /api/training/materials/library call identical Zod schemas and services as MCP. Exact existing scopes at pinned main: lib/server/agent-oauth-core.ts declares SCOPES = ["coach:read", "coach:write"] and lib/server/agent-tools.ts uses coach:read for reads/previews/exports and coach:write for commits. Use coach:read on every read and preview, including classification_suggest, export_page and import_preview; coach:write on every mutation/commit. Preserve purpose-limited business authorization and explicit confirmation for full library export/import; do not invent additional OAuth scope strings. Fail closed on revoked/off-scope/entitlement; no portal role. Registry source contains no ccp_material_library_ prefix in the inspected file. All local closed-world operations; annotate reads readOnlyHint=true, writes false, idempotentHint=true for request-bound commits, destructiveHint=true for removal/move/archive/import, false for read/add. Preview read-only and no DB/provider write. Never include provider token, private PGN or student details in summary.

Notation: U=UUID, R=nonnegative safe integer (DB bigint bounded at MAX_SAFE_INTEGER, fail closed on overflow); Name=1..80 normalized scalar chars; Desc=0..500; Path=Name[1..12]; Cursor=opaque signed string <=2048; Page={limit?:integer 1..100 default30,cursor?:Cursor}; Ref={id:U} OR {path:Path} OR {name:Name} exclusive, nested object (root never union). Mutation IDs only after resolving; root parent explicitly null. Strict objects, required unless ?, nullable only marked; arrays bounded, duplicate IDs rejected. Page cursors bind owner/filter/order/revision/expiry; organization list stale -> STALE_CURSOR; material list and export capture ordered IDs and relevant material revision/archive fingerprint under bounded consistent snapshot, reject stale cursor when changed, never claim complete on truncated response. Cursor design subject to query-plan validation; do not store full snapshot in token. Names across branches disambiguate by full path, exact normalized match only. Missing/foreign UUID same NOT_FOUND. Candidate lists paged, never auto-pick top. Timestamps ISO UTC.

Response envelope success {ok:true,data:T}; failure {ok:false,error:{code: enum, message:string, currentRevision?:R, candidates?:Collection[], nextCursor?:Cursor}}. Codes INVALID_INPUT, UNAUTHENTICATED, FORBIDDEN, NOT_FOUND, AMBIGUOUS_COLLECTION, NAME_CONFLICT, CYCLE, DEPTH_EXCEEDED, LIMIT_EXCEEDED, ARCHIVED_TARGET, STALE_REVISION, STALE_CURSOR, STALE_PREVIEW, PREVIEW_EXPIRED, CONFIRMATION_REQUIRED, IDEMPOTENCY_CONFLICT, RETRYABLE_CONFLICT. No raw SQL errors or foreign IDs. All list results explicitly nextCursor:null|string, libraryRevision:R. Collection={id:U,parentId:U|null,name:Name,description:Desc,sortOrder:integer,revision:R,archivedAt:timestamp|null,path:Path,childCount:nonnegative integer,directActiveMaterialCount:nonnegative integer}. MaterialSummary={id:U,title:string,kind:game|puzzle|drill|study_chapter|external_link,revision:R,archivedAt:timestamp|null,activeCollectionCount:integer}. Receipt={requestId:U,operation:string,libraryRevision:R,replayed:boolean,changedCollections:integer,addedMemberships:integer,removedMemberships:integer,collectionIds:U[] (max2000),materialIds:U[] (max100)}; only bounded IDs, no material bodies. Plan={token:string,expiresAt:timestamp,libraryRevision:R,affectedCollections:integer,affectedMemberships:integer,added:integer,removed:integer,conflicts:{code:string,path:Path}[] (max100),committable:boolean,previewChanges:Change[] (max100),moreChanges:boolean}; exact target IDs/read-back, not merely counts. W={requestId:U,expectedLibraryRevision:R}. ReviewCommit={...W,previewToken:string,confirmed:true}; token binds exact full normalized input, not just counts, commit requires same actor + current authorization and revision; conflicts never committable.

Conditional inputs: collectionId required iff view=collection; descendants allowed only there. includeArchived explicit; collection_get can return owned archived row; name-only resolution includes active by default. Reads never infer teaching status. Change is tagged union inside strict root: {type:create,localId:U,parentId:U|null,name:Name,description:Desc}; {type:rename,id:U,name:Name,description:Desc}; {type:move,id:U,parentId:U|null,beforeId:U|null}; {type:add|remove,materialId:U,collectionId:U}. Local IDs referenced only within same reviewed plan, collision with existing canonical ID rejected; topological create first; reject conflicting changes to same field, cycles, duplicates and exceeding bounds; preserve ordered intent. No archive nested in bulk change. TemplateNode={key:string 1..64,parentKey:string|null,name:Name,description:Desc,order:integer 0..99}; validate unique keys, parent references, cycles and order; custom edits/omissions explicit, no automatic merge. Preview conflicts require editing/resubmission, not silent skip. Empty template application is skip/no write. Suggestions deterministic candidate retrieval from own names/title/kind/source metadata; agent may propose reason from context, no generated categories in service output; create inferred structure only reviewed restructure, ordinary explicit single create permitted. Explicit uniquely resolved placement uses add without extra confirmation; duplicate add no-op with receipt. Remove missing owned pair is no-op; foreign/archived target not bypassed. Inferred add requires teacher approval at conversation/UI boundary; preview/commit mandatory for bulk, inferred new structures, move, archive/restore, template/import. No claim server can infer natural-language consent; use platform user approval and explicit confirmed intent.

ExportRow tagged union: {type:collection,sourceId:U,parentSourceId:U|null,name:Name,description:Desc,sortOrder:integer,archivedAt:timestamp|null,archiveBatchId:U|null} or {type:membership,collectionSourceId:U,materialSourceId:U}. Export excludes material contents, evidence, credentials; complete teacher backup remains authoritative. Stable ordered pages: parents before children, membership after collections; canonical source IDs only preserved in same-owner empty restore if verified, ordinary import uses explicit mappings, new UUID for unmapped collections, return mappings in receipt extension {collectionMappings:{sourceId:U,targetId:U}[] max100}. Cross-account imports never trust source UUID as ownership; require target material ID from canonical import mapping or explicit owned material mapping, no title heuristic, fail on unmapped link. Archived collection import initially only into fresh authorized restore or explicit reviewed archive state, no auto-unarchive; full backup preserves exact IDs and batch tokens. Interactive import is atomic per reviewed <=100 rows; parent-first chunks visible, checkpoint and new confirmation each chunk; no misleading all-or-nothing whole-library claim. Larger restore via existing reviewed backup pipeline only, not new unbounded MCP. Export consistency across pages must detect changes or restart; no hidden partial snapshot. No overwrite of material content/history.

All response schemas, field forwarding, error mappings and annotations test exact types and nondefault values. Name uniqueness and limits are proposals, not yet source. No new tool exposed until approved persistence and parity implementation.
